# Herbarium — Roadmap 2027

## Obiettivo
Costruire un prodotto botanico che unisca affidabilità scientifica, utilità quotidiana, apprendimento, esplorazione reale e un Libro digitale/fisico memorabile.

## Stato dopo v0.4

### Fondamenta attive

- Field AI Pack opzionale.
- acquisizione multi-view.
- quality gate fotografico.
- ProofID 4.0 con evidence ledger.
- Context Engine.
- Look-Alike Engine.
- Flora Italia Core seed.
- Game World / spedizioni / missioni.
- Living Atlas coordinate-first.
- Academy foundation.
- Book Renderer v4.
- backup locale e privacy-first.

## v0.5 — Gold Standard
Priorità massima:

1. Flora Pack Italia completo e versionato.
2. Gold Benchmark separato dal training.
3. confidence calibration misurata.
4. false-confident benchmark per famiglia/specie/organo.
5. gateway multi-engine con provenance.
6. Map Pack Italia ufficiale e offline.

**Gate di uscita:** Herbarium non mostrerà una percentuale utente come “affidabilità” finché non sarà calibrata sul Gold Benchmark.
